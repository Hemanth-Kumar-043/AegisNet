# AegisNet
Privacy-preserving cross-bank fraud detection: local differential privacy + federated learning (FedAvg) + simulated secure aggregation, with a merge step meant for IBM LinuxONE (s390x).

```
app.py             router: page config, CSS, background, top navigation
views/             home, federation, privacy, secure, alerts, laundering, data, linuxone
ui/                theme, styles (hover glow + page fade), components, html_blocks (hero + slider),
                   alert_console (alert page), laundering_map (case route map), worldmap, shared
core/              data_gen, privacy, federated, secure_agg, platform_proof, aml (red-flag scanner), aml_cases (historic cases)
data/              synthetic bank_a/b/c.csv + global_holdout_test.csv
notebooks/         01 data+privacy, 02 federated training, 03 secure aggregation + LinuxONE proof
scripts/           verify.py, run_local.sh, setup_linuxone.sh, generate_dataset.py, build_notebooks.py
.streamlit/        dark theme config
```

Run locally: `bash scripts/run_local.sh` (needs Python 3.9+, Streamlit 1.50+), or
`pip install -r requirements.txt && python scripts/verify.py && streamlit run app.py`

LinuxONE VM (Ubuntu s390x): see the section below.

Notes
- The Laundering page uses simplified public-record case summaries (Capone, BCCI, HSBC, Danske, Russian Laundromat, 1MDB) and a rule-based scanner on synthetic data. It does not use the federated model yet.
- The Alerts page is a simulation. Nothing is sent to any real police service.
- epsilon is applied per feature (about 10x epsilon per record) and labels are not noised.
- Secure aggregation masks are simulated in one process (no key exchange or dropout recovery).
- Only claim Secure Execution if /sys/firmware/uv/prot_virt_guest prints 1.


## Images
The banner and tile images are in `static/` and served by Streamlit (`enableStaticServing = true` in `.streamlit/config.toml`). Keep that setting, or the pictures will not load.

## Run on an IBM LinuxONE VM (s390x, Ubuntu)
pip has no prebuilt scipy / scikit-learn / pyarrow for s390x, so use the system packages:

```bash
git clone <this-repo-url> aegisnet && cd aegisnet
bash scripts/run_s390x.sh
```
The script installs the system packages, makes a venv that reuses them, installs Streamlit 1.50 without pyarrow
(`stubs/pyarrow` is a small stand-in so Streamlit can start; `app.py` then draws tables as plain HTML),
prints the proof numbers from `scripts/verify.py`, and starts the dashboard on 127.0.0.1:8501.
Reach it from your laptop with an SSH tunnel: `ssh -i key.pem -L 8501:localhost:8501 user@host`, then open http://localhost:8501.

Proof to capture on the VM: `uname -m` (s390x) and `lscpu`. Secure Execution is only claimed if
`cat /sys/firmware/uv/prot_virt_guest` prints 1.
